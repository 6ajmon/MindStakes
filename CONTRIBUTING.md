# Contributing to MindStakes

Thanks for taking the time to contribute. This page covers everything you need to build the project, follow the same workflow as the maintainers, and get a pull request merged.

## Requirements

| Tool | Version |
| --- | --- |
| Godot | 4.6.1 **.NET** build (not the standard build) |
| .NET SDK | 8.0 |
| Git LFS | any recent version |

Assets (images, audio) are stored with Git LFS, so install LFS **before** cloning:

```powershell
git lfs install
git clone https://github.com/6ajmon/MindStakes.git
```

## Build and run

```powershell
dotnet build MindStakes.sln
```

Then open `project.godot` in the Godot .NET editor and press <kbd>F5</kbd>.

To produce the same builds CI produces, use the export presets (`Windows Desktop`, `Linux`) or run the export from the command line:

```powershell
godot --headless --export-release "Windows Desktop" build/windows/MindStakes.exe
godot --headless --export-release "Linux" build/linux/MindStakes.x86_64
```

## Workflow

1. Open an issue (or pick an existing one) describing the change. Bug reports should include the Godot version, the OS, and steps to reproduce.
2. Create a branch from `main` named `<type>/<short-description>`, for example `fix/score-reset` or `feature/category-importer`.
3. Make the change, keep commits focused, and reference the issue in the pull request body (`Closes #12`).
4. Open the pull request. CI must pass before it can be merged: the solution has to build and both Godot exports have to succeed.
5. Do not push directly to `main`.

## Question data

Questions are **not** part of the repository. Only the two-question sample pool (`Resources/Questions/Pool1/1.tres` and `2.tres`) is tracked, and CI fails if anything else under `Resources/Questions/Pool*` is committed. See [README.md](./README.md) for how to point the game at an external questions folder.

## Scenes

`.tscn` files are generated by the Godot editor. Change them through the editor rather than by hand, and keep unrelated node/property churn out of the diff.

If you contribute with an AI coding agent, note that [AGENTS.md](./AGENTS.md) forbids agents from editing `.tscn` files directly and requires them to describe the required editor steps instead.

## Code style

- C# 12, four-space indentation, one class per file, `PascalCase` for types and members, `_camelCase` for private fields (the prevailing style in `Source/`).
- Keep existing architecture: game logic and managers live in `Source/`, data models in `Source/Data/`, scenes in `Source/Screens/` and `Source/Components/`.
- Avoid unrelated refactors in a pull request.

## Pull request checklist

- [ ] `dotnet build MindStakes.sln` passes.
- [ ] The change is linked to an issue.
- [ ] No question data (`.tres` under `Resources/Questions/Pool*`) is added to the repository.
- [ ] Documentation (`README.md`, this file) is updated when behaviour or setup changes.
- [ ] Scenes, if any, were changed through the Godot editor.

## Reporting security issues

Please do not report vulnerabilities in public issues. Follow [SECURITY.md](./SECURITY.md) instead.

By participating you agree to the [Code of Conduct](./CODE_OF_CONDUCT.md).
